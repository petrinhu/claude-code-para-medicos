Skills Custom (Codeberg do Dr. Petrus)

Clonar uma vez em ~/.claude/skills/. Ativadas com /nome-da-skill dentro do Claude Code.

git clone https://codeberg.org/petrinhu/forgejo-skill.git ~/.claude/skills/forgejo git clone https://codeberg.org/petrinhu/memo_persistente.git ~/.claude/skills/memo_persistente git clone https://codeberg.org/petrinhu/tab_pendencias.git ~/.claude/skills/tab_pendencias
Skill Comando O que faz
Forgejo /forgejo Controla repositorios no servidor Forgejo/Codeberg: cria issues, abre PRs, lista commits, sem sair do terminal
Memo Persistente /memo_persistente Salva memorias importantes entre sessoes. O Claude lembra de preferencias, decisoes e contexto do projeto indefinidamente.
Tabela de Pendencias /tab_pendencias Gera tabela de tarefas ordenada por prioridade (WSJF): mostra o que tem maior valor de negocio com menor esforco

Verificar com /mcp dentro do Claude Code. Requer reinicializacao apos instalar novo MCP.

forgejo Ativo Gerencia repositorios Forgejo/Codeberg: equivalente ao GitHub para servidores proprios

Google Drive Ativo Acessa, le e cria arquivos no Google Drive sem sair do Claude
playwright Ativo Controla o navegador de forma automatizada: preenche formularios, navega, captura tela
desktop-commander Ativo Controla o desktop: abre apps, gerencia processos, le e edita arquivos do sistema
chrome-devtools Ativo Acessa DevTools do Chrome: inspeciona rede, DOM, performance, screenshots
microsoft-docs Ativo Busca documentacao oficial Microsoft e Azure diretamente na conversa
hostinger Ativo Gerencia hosting, dominios e VPS na Hostinger pelo Claude
Crypto.com Ativo Dados de mercado de criptomoedas em tempo real (menos relevante para clinica)
Gmail Requer auth Le e envia emails do Gmail: requer autenticacao Google
Google Calendar Requer auth Le e cria eventos no Google Agenda: requer autenticacao Google

Referencia Rapida: Comandos Essenciais

Situacao Comando
Instalar plugin oficial /plugin install superpowers@claude-plugins-official
Ver MCPs instalados /mcp
Gerar tabela de pendencias /tab_pendencias
Salvar memoria persistente /memo_persistente
Controlar Forgejo/Codeberg /forgejo
Iniciar nova sessao claude
Retomar ultima conversa claude -c
Instalar uv (Windows - PowerShell) powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
Criar projeto Python com uv uv init nome-do-projeto
Ver agentes disponiveis ls ~/.claude/agents/ | sort
