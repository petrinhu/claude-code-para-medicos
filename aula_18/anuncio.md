## Médio (descrição de vídeo / e-mail)

Você já conecta o Claude a fontes externas, já chama skills pelo nome e já instalou um plugin, tudo isso há semanas, sem parar para nomear cada peça. Nesta aula a gente organiza esse conhecimento: MCP é o cabo que liga o Claude a ferramentas externas, skill é o protocolo que você invoca, plugin é o kit que empacota tudo numa instalação só. E então entra o quarto conceito, o único novo: o hook, uma automação que dispara sozinha quando algo acontece no projeto. É como escolher o instrumental certo para cada procedimento, deixando o Claude mais afinado com o jeito que você trabalha no ClinMd-Tribe.
