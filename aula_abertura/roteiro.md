**Tom:** Colega com humor leve e didático

## SEÇÃO 3: DESMISTIFICAR Claude Code (5 min)

**Tom:** Colega explicando como se fosse um protocolo novo

"Primeiro, deixa eu tirar alguns medos do caminho.

Claude Code NÃO é mágica. É uma ferramenta. Que funciona MUITO bem, 
mas é uma ferramenta. Vocês acham que IA é magia porque não entendem como funciona.
É como paciente achar que ressonância magnética é bruxaria — não é, é física.
Claude Code é a mesma coisa.

Claude Code NÃO transforma vocês em programadores. Não é pra programar.
É pra **delegar** trabalho técnico. Vocês descrevem o problema em linguagem natural,
Claude faz o código. Vocês só validam se ficou bom.

Claude Code NÃO vai roubar seu emprego de médico. Pelo contrário: 
médico que aprende a usar IA vai ser muito mais valioso que médico 
que fica vendo IA fazer tudo sem entender.

O que Claude Code É:
Uma ferramenta de colaboração. Você tem uma ideia, descreve pro Claude, 
ele executa. É como ter um dev junior muito competente no seu consultório, 
24h disponível, nunca fica cansado, nunca briga com gerente.

Vocês controlam tudo. Vocês decidem se fica bom ou não. 
Vocês mostram o caminho, Claude executa. Vocês continuam no controle.

Pense assim: é como quando vocês consultam um especialista.
Vocês têm o problema clínico, descrevem pro colega especialista, 
ele dá a solução baseado na experiência dele. 
Claude funciona assim — mas é especialista em código, terminal, IA.

Fácil? Fácil."

## SEÇÃO 4: INSPIRAÇÃO (5-6 min)

**Tom:** Possibilidades concretas, cases práticos no universo médico

"Agora vem a parte legal. O que vocês vão conseguir fazer ao final deste curso?

Vocês conhecem o TribeMD Assist? É o app que vocês já usam aqui na plataforma.
Tem transcrição de consulta automática — você fala, a IA transcreve.
Tem extração de dados de exame — você anexa um PDF de laboratório, 
a IA lê, entende os resultados, joga direto no PEP. Tem professores virtuais 
que interagem com inteligência artificial. Tem suporte já com IA respondendo.

Pois bem. Vocês vão entender COMO essas coisas funcionam. 
Não vão programar, mas vão entender a lógica por trás.

E vocês vão criar versões customizadas disso pra vocês mesmos.

Imagine: vocês estão estudando pra prova de título, ou querem acompanhar 
a literatura nova do seu tema. Vocês vão conseguir:
— Buscar artigos no PubMed diretamente pelo Claude Code (isso chama MCP, explicamos depois)
— Ver resumos estruturados em segundos
— Fazer fichamento com PICO, nível de evidência, vieses
— Gerar flashcards Anki automaticamente pra revisar
— Receber briefing toda manhã: 'novidades do seu tema'

Tudo sem sair do Claude Code. Tudo sem ler o artigo inteiro se não quiser.

Avançamos mais. Vocês têm indicadores do consultório que quer monitorar —

No final deste curso, vocês vão conseguir ler artigos mais rápido,

## SEÇÃO 5: CONTRATO (4-5 min)

**Tom:** Claro, direto, transparência sobre expectativas

"Deixa eu ser direto sobre o que é este curso e o que não é.

Este curso tem 22 aulas obrigatórias + 31 aulas opcionais na fase avançada.
Cada aula dura cerca de 1 hora. Idealmente, uma aula por semana.

Ele se divide em 3 fases bem claras:

**FASE 1 — INICIANTE:** 8 aulas, sem programação.
Vocês aprendem a instalar, conversar com Claude Code, resumir documentos,
gerar apresentações, organizar planilhas. É puro uso. Nada de código.

**FASE 2 — INTERMEDIÁRIO:** 9 aulas, sem programação.
Agora vocês aprendem a buscar na PubMed, fazer fichamento crítico, 
gerar flashcards, criar conteúdo (posts, newsletter), analisar dados de pesquisa,
organizar consultório. Ainda é uso, ainda é sem código.

**FASE 3 — AVANÇADO (OPCIONAL):** 31 aulas, com um pouco de programação.
Agora sim vocês aprendem Python, Flet, como construir apps e dashboards.
Calculadoras clínicas, gerador de evolução, RAG local, testes, CI/CD.
Tudo isso é opcional — quem não quer programar para depois na fase 2.

Agora a parte crítica. Este curso vive em volta de UM EIXO TRANSVERSAL:
**LGPD e PRIVACIDADE.**

A regra de ouro é simples: **DADO DE PACIENTE NÃO ENTRA.**
Nunca. Nenhuma informação de paciente sai do seu consultório.

Quando vocês usam Claude Code, vocês anexam um PDF, um áudio, uma planilha.
Claude Code processa, mas não aprende. Não fica no servidor da Anthropic.
Não vira dado de treinamento.

E o registro clínico continua no PEP — a ferramenta aqui complementa a prática,
não substitui o prontuário.

Última coisa: este curso vai exigir que vocês fiquem confortáveis com terminal.
Não é programar — é digitar comandos que eu vou dar prontos.
Tipo receitar remédio: vou passar a dose, vocês só copiam e colam.

Perguntas? Não? Ótimo. Vamos instalar."

## SEÇÃO 7: TERMINAL DESMEDO + História (8-10 min)

**Tom:** Desarmador, histórico, analogia clínica

"Perfeito. Agora vou mostrar que tudo é igual — e vou voltar pro meu Linux depois.

Mas antes: vamos falar de terminal. Muita gente tem medo de terminal.
'Aaah, terminal é coisa de hacker', 'preciso saber programar'...

Mentira. Deixa eu contar a história.

Nos anos 70, computador era MAINFRAME — uma máquina gigante que ocupava 
uma sala inteira. Mainframe custava centenas de milhares de dólares.
Não era de um só pessoa, era de uma empresa inteira.

Então como as pessoas acessavam? Elas tinham um TERMINAL — basicamente 
uma tela e um teclado conectados ao mainframe por um cabo.
O terminal não fazia cálculo, não fazia nada. Era SÓ uma forma de comunicação.
Você digita um comando, o mainframe processa, volta a resposta na tela.

Terminal = comunicação com a máquina.

Nada mais. Não é mágica, não é hacker.

Hoje em dia, terminal é a mesma coisa. Você abre uma janela preta,
digita um comando, o computador executa, mostra resultado.

Tipo receita clínica. Eu prescrevo: 'dipirona 500mg, 6/6h'. 
Você não questiona se é possível, você só segue a receita.
Aqui é a mesma coisa. Eu passo o comando, vocês copiam, colar e Enter.
Pronto.

[ele mostra o PowerShell aberto]

Tá vendo? Isto é o PowerShell do Windows.
Aparentemente assustador, mas é SÓ uma caixa onde eu digito.

Vou mostrar alguns comandos que vocês vão usar:

Primeiro: **cd** — significa 'change directory', mas sem argumentos 
mostra em que pasta vocês estão. Tipo: 'em qual consultório vocês estão?'

[ele digita: cd]

Segundo: **dir** — list, mostra quais arquivos estão aqui.
Tipo: 'quais prontuários tem nessa pasta?'

[ele digita: dir]

Terceiro: **cd caminho** — vocês entram em uma pasta.
Tipo: 'vou pro consultório 2'.

[ele digita: cd Documents]

Pronto. Estes três comandos cobrem 90% do que vocês vão fazer.
- **cd** (sem argumento): 'onde estou?'
- **dir**: 'o que tem aqui?'
- **cd caminho**: 'vou pra lá'.

Além disto, Claude Code faz o resto. Vocês só copiam comando que ele gera.

Agora uma regra de ouro que vai salvar vocês muitas vezes:

**O Claude Code sempre trabalha na pasta onde você está quando o abre.**

Se você quer que ele leia seus PDFs de artigos, seus arquivos de pesquisa,
suas planilhas — você precisa abrir o Claude Code já dentro da pasta certa.

É como dizer pro residente: 'o prontuário está na sala 3'.
Se ele for pra sala errada, não vai achar nada.

Na prática: antes de abrir o Claude Code, navegue até a pasta do seu projeto:

```
cd Documents\meus_artigos
```

Aí então abre o Claude:

```
claude
```

Ele vai enxergar tudo que está nessa pasta. Simples assim.

Agora vou voltar pro meu Linux. Vai parecer diferente, mas é a mesma lógica.

[ele volta pro Linux]

No Linux, os comandos têm nomes diferentes — 'pwd' em vez de 'cd', 
'ls' em vez de 'dir' — mas é o MESMO conceito. Mesma lógica.
Só ortografia diferente.

Fácil? Fácil."
