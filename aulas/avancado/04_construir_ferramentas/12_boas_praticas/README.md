# Submódulo 12: Boas Práticas de Desenvolvimento

**Fase:** Avançado | **Aulas:** 3 | **Pré-requisito:** Submódulos 00 a 11

Três erros que acabam com projetos reais: vazar token de API, criar um monolito que ninguém consegue manter, e desenvolver sem consultar os agentes da equipe. Esta aula ensina a evitar os três.

| # | Aula | Duração |
|---|------|---------|
| 01 | Segurança: nunca suba seu token de API | 1h |
| 02 | Arquitetura modular: evitando o monolito | 1h |
| 03 | Workflow com agentes: sempre discuta com o time | 1h |
