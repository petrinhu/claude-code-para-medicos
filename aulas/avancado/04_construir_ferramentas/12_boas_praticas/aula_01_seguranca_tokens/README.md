# Seguranca: nunca suba seu token de API

## Objetivo
Proteger suas credenciais de API (Claude, OpenAI, etc.) para nunca vazar um token no repositorio publico.

## Pre-requisitos
Submodulo 01 (Git). Ter uma chave de API criada.

## O que voce vai entregar
- [ ] Arquivo .env criado e funcionando localmente
- [ ] .env no .gitignore confirmado
- [ ] Variaveis de ambiente lidas corretamente no codigo
- [ ] Repositorio verificado: nenhum token nos commits

## Duracao estimada
1 hora
