# Módulo 04 — Construir suas Próprias Ferramentas

**Fase:** Avançado (Opcional) | **Pré-requisito:** Fase Intermediária

Aqui você aprende a programar com Python e Flet para construir o ClinMd-Tribe: calculadoras, RAG, dashboard e app exportável como .exe.

**Case do módulo:** construir um app local que reúne calculadora de escores e um dashboard de indicadores que atualiza sozinho, empacotado para rodar offline na máquina do médico.
