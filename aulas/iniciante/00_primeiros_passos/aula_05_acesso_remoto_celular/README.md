# Aula 05: Claude Code no Celular via Acesso Remoto

## Objetivo
Acessar o Claude Code do seu PC remotamente pelo celular usando o comando `/remote`, sem precisar estar na frente do computador.

## Pré-requisitos
- Aula 00.02 (instalação do Claude Code no PC)
- PC ligado e com Claude Code instalado
- Celular com navegador ou app Claude

## O que você vai entregar
- [ ] PC configurado para aceitar conexão remota
- [ ] Primeira sessão aberta pelo celular
- [ ] Exercício prático feito 100% pelo celular

## Duração estimada
1 hora
