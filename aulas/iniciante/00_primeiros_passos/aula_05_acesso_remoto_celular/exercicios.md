# Exercícios: Claude Code no Celular via Acesso Remoto

## Exercício 1: Primeira sessão remota

No PC, inicie o modo remoto e acesse pelo celular:

```bash
/remote
```

Pelo celular, envie o prompt:
```
Liste 3 situações do meu dia a dia médico onde o acesso remoto ao Claude Code seria útil.
```

Tire um print da resposta no celular e salve como prova de conclusão da aula.

## Exercício 2: Exercício de uma aula anterior pelo celular

Escolha qualquer exercício das aulas 01 a 04 que você não terminou. Faça ele 100% pelo celular via `/remote`. Objetivo: sentir a diferença de fluxo entre PC e celular.

## Exercício Bônus: Teste de velocidade

No celular via `/remote`, peça:
```
Resuma em 5 bullets o que é o Claude Code para um colega médico que nunca ouviu falar.
```

Tempo limite: tente completar em menos de 3 minutos desde abrir o `/remote` até ter a resposta na tela.

## Gabarito

Não há resposta errada. O objetivo é confirmar que a conexão funciona e que você consegue usar o Claude Code pelo celular com fluidez.

Critério de aprovação: conseguiu abrir a sessão remota e receber ao menos uma resposta pelo celular.
