## Contexto

Primeira aula do curso "Claude Code para Médicos" (MDlife Academy). Segue o roadmap canônico: M1 — Assistente de Produtividade. Público: médicos experientes, zero em TI.

## Abordagem escolhida

**Narrativa clínica contínua:** o aluno é colocado num cenário real desde o início — precisa preparar uma aula sobre depressão pra residentes em 1 hora — e cada demo é um passo natural desse preparo.

## Estrutura (8 seções)

| # | Seção | Duração | Observações |
|---|-------|---------|-------------|
| 1 | Abertura | 3 min | Ponte com aula_abertura |
| 2 | O Cenário | 2 min | Estabelece o desafio do dia |
| 3 | Demo: PDF | 12 min | Resumir guideline de depressão — Sonnet |
| 4 | Modelos + Tokens | 8 min | Haiku/Sonnet/Opus, custo x eficácia, como trocar |
| 5 | Demo: Planilha | 8 min | Organizar dados anonimizados — Haiku |

| 7 | Demo: Folheto | 8 min | Folheto pós-consulta — Sonnet |
| 8 | Encerramento | 3 min | Resumo + ponte pra aula_02 (PubMed) |

**Total: ~56 min**

## Tema clínico

Depressão — estrutura validada:
1. Epidemiologia
2. Etiopatogenia / Neurobiologia
3. Quadro clínico e diagnóstico (DSM-5/CID-11)
4. Diagnóstico diferencial
5. Tratamento (farmacológico, psicoterápico, ECT, estimulação magnética)
6. Casos especiais / Depressão refratária

## Integração de modelos

- **Sonnet:** demos complexas (PDF, slides, folheto) — raciocínio e síntese
- **Haiku:** demo de planilha — tarefa simples, rápida, barata
- **Seção 4 dedicada:** explica os 3 modelos, tokens (o que é, custo, limite de contexto), como trocar de modelo na prática

## Formato do roteiro

Seguir **canonicamente** a estrutura de `aula_abertura/roteiro.md`:
- Seções numeradas com emoji
- Cada seção: duração + **Tom:** + texto de fala entre aspas
- Demos ao vivo (screencast)
- Exemplos médicos reais

- Roadmap (`roadmap.html`) define o conteúdo de cada aula — nunca desviar sem aprovação
- Estrutura do MD segue sempre o padrão da aula_abertura
