## Abordagem escolhida

**Narrativa clínica contínua:** reunião clínica sobre fibrilação atrial amanhã — médico precisa de evidência atual sobre anticoagulação. Cada demo é um passo natural desse preparo.

## Tema clínico

Fibrilação atrial — foco em anticoagulação (guidelines ESC/AHA).

## Estrutura (8 seções, ~55 min)

| # | Seção | Duração | Observações |

| 1 | Abertura | 2 min | Ponte com aula_01 |

**Total: ~55 min**

## Conteúdo por seção

**Seção 3 — MCP (conceito):** explicar que MCP = conector que dá ao Claude acesso a ferramentas externas (PubMed, Google Calendar, etc.). Analogia: como ligar um aparelho de ECG ao computador — o computador já sabe processar sinais, só precisa do cabo certo.

**Seção 4 — Setup:** mostrar como instalar o conector PubMed no Claude Code. Comandos prontos para copiar.

**Seção 5 — Busca:** prompt estruturado para buscar artigos de FA + anticoagulação. Mostrar filtros (ano, tipo de estudo, idioma).

**Seção 6 — Triagem:** como pedir ao Claude para selecionar os artigos mais relevantes por critério clínico (RCT, metanálise, guideline).

**Seção 7 — Fichamento:** prompt para extrair PICO, classificar nível de evidência (Oxford/GRADE), identificar vieses principais (seleção, aferição, confundimento). Resultado: ficha pronta para usar em reunião.
