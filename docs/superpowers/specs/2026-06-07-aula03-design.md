## Contexto

Terceira aula do curso. Completa o M2 (Aprender e acompanhar a literatura) com os tópicos M2.03 e M2.04. Público: médicos experientes, zero em TI.

## Abordagem escolhida

**Narrativa clínica contínua:** médico se preparando para prova de título em endocrinologia + querendo receber novidades do tema automaticamente todo dia.

## Tema clínico

Diabetes tipo 2 — guideline ADA (American Diabetes Association).

## Estrutura (6 seções, ~50 min)

| # | Seção | Duração | Observações |
|---|-------|---------|-------------|
| 1 | Abertura | 2 min | Ponte com aula_02 |
| 2 | O Cenário | 3 min | Prova de título + manter-se atualizado |
| 3 | Demo: Flashcards Anki | 15 min | Gerar cards da guideline ADA, exportar .txt, importar no Anki |
| 4 | Demo: Briefing manual | 8 min | Prompt salvo para rodar toda manhã |
| 5 | Demo: Briefing automático | 12 min | Agendar via cron (Linux) / Task Scheduler (Windows) |
| 6 | Encerramento + dever de casa | 5 min | Criar flashcards do próprio tema |

**Total: ~50 min**

## Detalhes por seção

**Seção 3 — Flashcards Anki:**
- Anexar ou buscar guideline ADA sobre DM2
- Prompt para gerar 15-20 flashcards no formato frente/verso
- Exportar em .txt (formato Anki: `frente;verso`)
- Mostrar como importar no Anki com um clique

**Seção 4 — Briefing manual:**
- Criar um prompt salvo para buscar novidades de DM2 no PubMed (últimos 7 dias)
- Salvar o prompt em arquivo .txt para reusar diariamente
- Mostrar resultado: resumo das publicações da semana

**Seção 5 — Briefing automático:**
- Mostrar primeiro a versão manual (seção 4 como base)
- Linux: cron job para rodar o prompt e salvar resultado em arquivo diário
- Windows: Task Scheduler com comando equivalente
- Resultado: arquivo de briefing gerado automaticamente toda manhã
