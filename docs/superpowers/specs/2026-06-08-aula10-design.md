## Contexto

Primeira aula da Fase Avançada (M4). Marca a transição do Claude Code sem código para o desenvolvimento real de um app clínico. Faz o reveal do ClinMd-Tribe e instala todo o ambiente profissional de desenvolvimento: plugin oficial, skills custom, 65 agents e MCPs.

## Objetivos

1. Revelar o produto capstone: ClinMd-Tribe
2. Instalar plugins, skills, agents e MCPs — jeito difícil (comandos manuais) + jeito fácil (Claude instala sozinho)
3. Ensinar quando reiniciar o Claude e como retomar com `claude -c`
4. Criar o projeto com `uv init clinmd-tribe`

## Detalhes por seção

### Plugin oficial (Seção 4)
- Comando: `/plugin install superpowers@claude-plugins-official`
- Docs: https://docs.anthropic.com/pt/claude-code/plugins
- Depois de instalar: reiniciar o Claude Code

### Skills do Petrus — Codeberg (Seção 4)
- forgejo: `git clone https://codeberg.org/petrinhu/forgejo-skill.git ~/.claude/skills/forgejo`
- memo_persistente: `git clone https://codeberg.org/petrinhu/memo_persistente.git ~/.claude/skills/memo_persistente`
- tab_pendencias: `git clone https://codeberg.org/petrinhu/tab_pendencias.git ~/.claude/skills/tab_pendencias`

### Agents (Seção 5)
- 65 agents em `~/.claude/agents/` (12 C-levels + 53 operacionais)
- Jeito difícil: criar manualmente arquivo `.md` em `~/.claude/agents/` para cada agent
- Jeito fácil: `claude "Baixe todos os agents do repositório https://codeberg.org/petrinhu/claude-memory — cada arquivo .md da pasta agents/ deve ser salvo em ~/.claude/agents/"`

### MCPs (Seção 6)
- Listagem via `/mcp` no Claude Code
- 11 ativos: Canva, Google Drive, playwright, pubmed, microsoft-docs, desktop-commander, hostinger, chrome-devtools, forgejo, github, Crypto.com
- 2 precisam autenticação: Gmail, Google Calendar
- skills.html documenta todos com descrição resumida

### Quando reiniciar (Seção 7)
- Após `/plugin install`: reiniciar obrigatório
- Após instalar MCP: reiniciar obrigatório
- Para continuar última conversa: `claude -c`

### uv (Seção 8)
- Instalação: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Criar projeto: `cd ~/Documents && uv init clinmd-tribe`
- Estrutura gerada: `.python-version`, `main.py`, `pyproject.toml`
- Analogia médica: uv = farmácia que organiza os remédios do projeto

### skills.html
- Arquivo separado em `aula_08/skills.html`
- Tabela de referência de todos agents, skills, MCPs com descrição breve
- Estilo TribeMD (#5213B9, Inter)
- Commitado e pushado como referência permanente para o aluno
