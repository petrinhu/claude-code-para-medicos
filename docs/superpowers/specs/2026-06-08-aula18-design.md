## Objetivo de aprendizagem

Ao final da aula, o aluno:

1. Reconecta os três conceitos conhecidos (MCP, skill, plugin) a uma analogia unificada do plantão
2. Sabe ler o arquivo interno de uma skill e entender que é texto, não código
3. Usa o GitHub MCP no contexto do ClinMd-Tribe para consultar o histórico do projeto
4. Entende o que é um hook — rotina automática do plantão — e vê um ao vivo
5. Distingue o que ele convoca (`/skill`, `@mcp`) do que o sistema convoca (hook)

**O aprofundamento:** mostrar que `/tab_pendencias` é um arquivo de texto.

Prompt ao Claude Code:
```
Leia o arquivo da skill tab_pendencias e me mostre o conteúdo completo.
```

Mensagem-chave: **a skill é um protocolo escrito que alguém deixou pronto**. Igual ao POP da UTI: não é mágica, é instrução formalizada. Você pode ler, entender e até pedir ao Claude que crie uma skill nova para você.

Analogia: skill = protocolo clínico institucional que qualquer residente novo segue quando entra no serviço.

## Seção 4 — Hooks: A Rotina Automática (6 min)

**O conceito novo.**

Analogia: "antes de toda alta, confere a prescrição" — dispara sozinho no evento, sem você pedir. É o reflexo do plantonista treinado, não a conversa.

Diferença central:
- Skills e MCPs: **você convoca** (`/tab_pendencias`, `@github`)
- Hooks: **o sistema convoca** (dispara no evento)

Mostrar onde hooks são configurados: arquivo `.claude/settings.json` do projeto.

Estrutura de um hook (mostrar na tela, não executar ainda):
```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write",
        "hooks": [{"type": "command", "command": "echo '✓ arquivo salvo pelo residente'"}]
      }
    ]
  }
}
```

Preencher linha 3 da tabela ao final da seção.

## Seção 5 — Demo de Hook ao Vivo (6 min)

Criar o hook no `.claude/settings.json` do ClinMd-Tribe via prompt:
```
No arquivo .claude/settings.json do projeto, adiciona um hook PostToolUse
que executa após qualquer operação Write e imprime no terminal:
'✓ residente salvou: [arquivo modificado]'
```

Fazer uma edição qualquer no projeto e mostrar a mensagem aparecendo automaticamente no terminal.

Mensagem-chave: o médico **vê acontecer sem pedir**. É o checklist cirúrgico que disparou antes da incisão — você não precisou lembrar.

Preencher linha 4 da tabela ao final da seção.

## Seção 6 — Tabela Completa: Os 4 Juntos (4 min)

Mostrar a tabela preenchida:

| Conceito | O que é | Como acionar | Análogo no plantão |
|----------|---------|-------------|-------------------|
| Skill | Protocolo escrito invocado pelo nome | `/nome` | POP da UTI |
| MCP | Cabo que conecta a ferramentas externas | `@nome` | PACS, laboratório, prontuário |
| Hook | Rotina automática disparada por evento | Automático | Checklist cirúrgico |
| Plugin | Kit que empacota skills + MCPs + hooks | `plugin install` | Maleta de admissão |

Três perguntas retóricas de revisão:
1. "Para buscar um artigo do PubMed, que tipo de extensão uso?" → MCP
2. "Para gerar a tabela de pendências, que tipo?" → Skill
3. "Para checar automaticamente se um arquivo foi salvo, que tipo?" → Hook
