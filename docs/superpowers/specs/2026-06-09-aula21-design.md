## Objetivo de aprendizagem

Ao final da aula, o aluno:

1. Escreve um prompt descritivo único que instrui o Claude Code a implementar a CHA₂DS₂-VASc respeitando a Clean Architecture das 4 camadas
2. Lê o código gerado com olho clínico — verifica se as regras do score estão corretas (pontuação dupla de A₂ e S₂, cutoffs por sexo)
3. Roda o app ao vivo (`uv run python main.py`) e vê o score calculado na tela Flet
4. Valida o app com 3 casos clínicos conhecidos, confirmando que o resultado bate com o cálculo manual

## Fio narrativo

**"Você anticoagula?"**

Cardiologista. Paciente de 68 anos, masculino, FA paroxística descoberta em checkup. HAS e DM. Sem AVC prévio. A pergunta que abre a aula não tem resposta imediata — ela exige um score. O cardiologista vai construir a ferramenta que responde essa pergunta. E ao final, vai testá-la no próprio caso.

A aula encerra com o cardiologista confiante de que o app não mente — porque ele testou com casos que ele já conhecia a resposta.

## Referência clínica — CHA₂DS₂-VASc

| Letra | Critério | Pontos |
|---|---|---|
| C | Insuficiência cardíaca congestiva (CHF) | 1 |
| H | Hipertensão arterial | 1 |
| A₂ | Idade ≥75 anos | **2** |
| D | Diabetes mellitus | 1 |
| S₂ | AVC / AIT / tromboembolismo prévio | **2** |
| V | Doença vascular (IAM, placa aórtica, DAP) | 1 |
| A | Idade 65–74 anos | 1 |
| Sc | Sexo feminino | 1 |

**Score máximo:** 9 (feminino) / 8 (masculino)  
**Cutoff de anticoagulação:** ♂ ≥2 → anticoagular · ♀ ≥3 → anticoagular

**Caso-âncora da aula (68M, HAS + DM):**
C0 + H1 + A₂0 + D1 + S₂0 + V0 + A1 + Sc0 = **3 → Anticoagular**

## Seção 2 — Clínica como especificação (10 min)

Não é revisão de cardiologia. É geração do critério de aceite.

> *"Você já sabe o que é CHA₂DS₂-VASc. Eu não vou te ensinar cardiologia. Vou te mostrar como transformar o que você já sabe em uma especificação que o Claude entende."*

Percurso:
1. Mostrar os 9 critérios com pontuação — destacar os duplos (A₂ e S₂)
2. Mostrar cutoffs por sexo
3. Calcular o caso-âncora à mão ao vivo: **score 3 → Anticoagular**
4. Salvar esse resultado: *"Esse é o gabarito. O app vai ter que bater esse número."*

---

## Seção 3 — O prompt descritivo (8 min)

Prompt que o aluno vai digitar ao vivo:

```
Implemente a calculadora CHA₂DS₂-VASc no ClinMd-Tribe respeitando a Clean Architecture:

domain/calculadoras/cha2ds2vasc.py
  - Classe Cha2ds2Vasc com campos: chf, has, idade, dm, avc_previo, doenca_vascular, sexo_feminino
  - Método calcular() → retorna score inteiro 0–9
    - idade ≥75: 2 pts; idade 65-74: 1 pt
    - avc_previo: 2 pts; demais critérios booleanos: 1 pt cada
    - sexo_feminino adiciona 1 pt
  - Método interpretar(score, sexo_feminino) → str
    - Homem: score ≥2 → "Anticoagular"; senão "Sem indicação no momento"
    - Mulher: score ≥3 → "Anticoagular"; senão "Sem indicação no momento"

application/servicos/calculadora_service.py
  - Função calcular_cha2ds2vasc(dados: dict) → dict com 'score' e 'recomendacao'

presentation/telas/calculadora_cha2ds2vasc.py
  - Tela Flet: checkbox para CHF, HAS, DM, AVC prévio, doença vascular
  - Campo numérico para idade; radio para sexo (M/F)
  - Botão "Calcular"
  - Exibir score em destaque; recomendação em verde (sem indicação) ou laranja (anticoagular)
```

Frase pedagógica: *"Você está escrevendo um protocolo clínico, não um programa. O Claude lê esse protocolo e escreve o programa por você."*

---

## Seção 5 — Leitura supervisionada (12 min)

Roteiro de perguntas clínicas que o cardiologista faz ao ler o código:

1. *"O campo `idade` está sendo usado para calcular A₂ (≥75=2pts) e A (65-74=1pt)?"* → checar `domain/`
2. *"O `avc_previo` está valendo 2 pontos, não 1?"* → confirmar lógica em `calcular()`
3. *"O `sexo_feminino` adiciona 1 ponto ao score final?"* → verificar
4. *"O cutoff para mulher está ≥3, não ≥2?"* → verificar `interpretar()`
5. *"A cor laranja aparece para 'Anticoagular'?"* → checar `presentation/`

Frase-âncora: *"Você não lê para entender Python. Você lê para assinar o laudo."*

## Seção 7 — Validação cruzada (5 min)

| Caso | Perfil | Cálculo | Score | Decisão esperada |
|---|---|---|---|---|
| 1 (âncora) | 68M, HAS + DM | H1+D1+A1 | 3 | Anticoagular |
| 2 | 55M, sem fatores | 0 | 0 | Sem indicação |
| 3 | 77F, CHF + HAS + AVC prévio | C1+H1+A₂2+S₂2+Sc1 | 7 | Anticoagular |

Analogia do learning-designer: *"Você não confia num aparelho de PA só porque ele apitou. Você compara com dois ou três pacientes que você conhece. Com o app é igual."*
