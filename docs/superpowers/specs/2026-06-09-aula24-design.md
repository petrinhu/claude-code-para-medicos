## Objetivo de aprendizagem

Ao final da aula, o aluno:

1. Implementa o MELD — primeiro score com fórmula contínua e logaritmos, primeiro uso de `float` no domínio
2. Entende a convenção `min=1.0` do MELD como regra clínica/matemática — e sabe que ela mora no domínio, não na UI
3. Implementa o MMSE — primeiro score com subtestes de pesos heterogêneos (limites 5/5/3/5/3/9)
4. Fecha o módulo S05 sabendo reconnecer e nomear os 3 paradigmas: booleano, Likert e fórmula/composto

## Decisões de design

| Decisão | Escolha | Motivo |
|---|---|---|
| Paradigmas | MELD (fórmula contínua) + MMSE (subtestes heterogêneos) | Dois padrões genuinamente novos não cobertos nas aulas 21–23 |
| Ordem | MELD primeiro | Salto cognitivo maior (float + logaritmo); MMSE é soma heterogênea — extensão do que o aluno já sabe |
| Persona | Dupla: hepatologista (MELD) + geriatra (MMSE) | Colar transplante hepático e demência num único caso seria artificial |
| Transfer deliberado | Não | Paradigmas diferentes entre si; cada um merece demo completa |
| Duração | ~58 min | Dois paradigmas novos + dois arcos narrativos + 7 perguntas de leitura |
| Estrutura | Arco duplo simétrico | MELD fecha completo, depois MMSE fecha completo — evita misturar paradigmas na leitura supervisionada |
| min=1.0 MELD | No domínio (`max(valor, 1.0)` antes do `math.log`) | Regra clínica; omitir na UI contradiz a aula_15 (dependência para dentro) |
| Pentágonos MMSE | Checkbox 0-1 dentro de `linguagem_praxia` + tooltip ⚙ com imagem de referência | Avaliação presencial; o app registra o resultado, não executa a prova |
| Validação MELD | 2 casos (âncora 20/19.6% + grave 31/52.6%) | Cobrir faixas médias e altas |
| Validação MMSE | 2 casos (âncora 20/leve + grave 7/<10) | Cobrir extremos |

**Dois paradigmas. Duas especialidades. Seis calculadoras.**

Hepatologista. Paciente de 58 anos, cirrose alcoólica, internado por descompensação. O MELD não é uma escala — é uma fórmula. O professor digita logaritmos em português e o Claude traduz para `math.log`.

Geriatra. Paciente de 72 anos, mulher, filha traz por esquecimento crescente há 6 meses. O MMSE não é soma simples — cada subteste tem um teto diferente. O app sabe o que é válido antes de calcular.

## Referência clínica — MELD

**Fórmula:** `MELD = 3.78 × ln(bilirrubina) + 11.2 × ln(INR) + 9.57 × ln(creatinina) + 6.43`

| Campo | Tipo | Restrição clínica |
|---|---|---|
| `bilirrubina_mg_dl` | float | min=1.0 (convenção — logaritmo de valor <1 geraria score negativo) |
| `inr` | float | min=1.0 |
| `creatinina_mg_dl` | float | min=1.0 |

**Score:** arredondado para inteiro, range 6–40

| Score | Mortalidade em 90 dias |
|---|---|
| < 10 | 3.7% |
| 10–19 | 6.0% |
| 20–29 | 19.6% |
| 30–39 | 52.6% |
| ≥ 40 | 71.3% |

---

## Referência clínica — MMSE

| Subteste | Campo | Máx |
|---|---|---|
| Orientação temporal | `orientacao_temporal` | 5 |
| Orientação espacial | `orientacao_espacial` | 5 |
| Registro | `registro` | 3 |
| Atenção e cálculo | `atencao_calculo` | 5 |
| Evocação (memória) | `evocacao` | 3 |
| Linguagem + praxia (incl. figura dos pentágonos) | `linguagem_praxia` | 9 |

**Score total:** 0–30  
**Faixas:** ≥24=Normal · 18–23=Comprometimento leve · 10–17=Comprometimento moderado · <10=Comprometimento grave

**Item dos pentágonos:** faz parte de `linguagem_praxia` (1 dos 9 pontos). Na UI: tooltip ⚙ ao lado do campo mostra a figura de referência. O médico avalia presencialmente e registra o subteste total.

## Gabaritos de validação

| Caso | Perfil | Calculadora | Valores | Score | Resultado |
|---|---|---|---|---|---|
| 1 (âncora) | 58M, cirrose alcoólica | MELD | bili=4.5 / INR=1.8 / crea=1.2 | **20** | Mortalidade 90d: 19.6% |
| 2 (grave) | Cirrose descompensada grave | MELD | bili=8.0 / INR=2.5 / crea=2.0 | **31** | Mortalidade 90d: 52.6% |
| 3 (âncora) | 72F, esquecimento × 6 meses | MMSE | ori_t=3/ori_e=4/reg=2/aten=3/evoc=1/ling=7 | **20** | Comprometimento leve |
| 4 (grave) | Idoso desorientado | MMSE | ori_t=1/ori_e=1/reg=0/aten=1/evoc=0/ling=4 | **7** | Comprometimento grave |

**Cálculo caso 1 (verificação):**  
3.78×ln(4.5) + 11.2×ln(1.8) + 9.57×ln(1.2) + 6.43  
= 3.78×1.5041 + 11.2×0.5878 + 9.57×0.1823 + 6.43  
= 5.685 + 6.583 + 1.745 + 6.43 = **20.44 → 20**

**Cálculo caso 2 (verificação):**  
3.78×ln(8.0) + 11.2×ln(2.5) + 9.57×ln(2.0) + 6.43  
= 3.78×2.0794 + 11.2×0.9163 + 9.57×0.6931 + 6.43  
= 7.860 + 10.262 + 6.633 + 6.43 = **31.19 → 31**

## Prompt MELD (professor conduz)

```
Implemente a calculadora MELD no ClinMd-Tribe
respeitando a Clean Architecture das 4 camadas:

domain/calculadoras/meld.py
  - Classe Meld com 3 campos float:
    bilirrubina_mg_dl, inr, creatinina_mg_dl
  - Método calcular() → score inteiro
    Fórmula: round(3.78*ln(bili) + 11.2*ln(INR) + 9.57*ln(crea) + 6.43)
    Antes de calcular: aplicar min=1.0 em cada campo
    (ex: bilirrubina_efetiva = max(bilirrubina_mg_dl, 1.0))
    Usar math.log (logaritmo natural)
  - Método interpretar(score) → str com faixa + mortalidade
    - score < 10:  "Mortalidade em 90 dias: 3.7%"
    - 10 a 19:     "Mortalidade em 90 dias: 6.0%"
    - 20 a 29:     "Mortalidade em 90 dias: 19.6%"
    - 30 a 39:     "Mortalidade em 90 dias: 52.6%"
    - >= 40:       "Mortalidade em 90 dias: 71.3%"

application/servicos/calculadora_service.py
  - Adicionar função calcular_meld(dados: dict) → dict
    Retorna: {"score": int, "mortalidade_90d": str}

presentation/telas/calculadora_meld.py
  - Tela Flet com:
    - 3 campos numéricos float (bilirrubina, INR, creatinina)
    - Botão "Calcular MELD"
    - Exibir score inteiro em destaque
    - Exibir mortalidade em 90 dias
    - Cor por faixa: <10 verde · 10-19 amarelo claro ·
      20-29 amarelo · 30-39 laranja · >=40 vermelho
```

## 4 perguntas de leitura supervisionada — MELD

1. *"Os campos são declarados como `float`, não `int`?"* → checar `domain/calculadoras/meld.py`
2. *"O `calcular()` usa `math.log` — logaritmo natural — não `math.log10`?"* → verificar a importação e a fórmula
3. **"O `min=1.0` está aplicado no domínio antes do `math.log` — não na tela?"** ← crítica (regra clínica mora no domínio)
4. *"A tela chama o serviço — não calcula direto?"* → checar `presentation/`

**Frase-âncora MELD:** *"O médico não digita logaritmo. Ele descreve a fórmula. O Claude codifica. Mas a regra clínica do min=1.0 mora no domínio — não na tela."*

---

## 3 perguntas de leitura supervisionada — MMSE

1. *"Cada subteste recusa valor acima do seu máximo? (`min(valor, maximo)` para cada campo)"* → checar `domain/calculadoras/mmse.py`
2. *"O cutoff de Normal é 24 — não 25?"* → verificar `interpretar()`
3. *"A tela chama o serviço — não calcula direto?"* → checar `presentation/`

**Frase-âncora MMSE:** *"Cada subteste tem um teto. O domínio sabe. A tela só registra."*
