## 2. Analogia central — CONTROLE DE QUALIDADE LABORATORIAL (amostra-controle)

Toda manhã, antes do primeiro paciente, o laboratório roda uma **amostra-controle** de valor verdadeiro conhecido (glicemia controle = 100 mg/dL). Lê 100 → calibrado, libera. Lê 130 → **trava tudo** até consertar. O controle testa **a máquina que vai medir o paciente**, não o paciente.

Mapeia 5 propriedades do TDD: (1) valor esperado conhecido **antes** = essência do TDD; (2) trava se falhar = teste vermelho bloqueia; (3) roda antes do paciente = teste antes do deploy; (4) testa a máquina, não o paciente = testa o código, não o usuário; (5) repetível/automático = pytest.

**Âncora:** *"O controle não pergunta como você está hoje. Ele já sabe a resposta certa — e checa se a máquina ainda acerta."*

Analogias de apoio: saída do pytest = **laudo de exame**; RED/GREEN = **monitor de UTI** (alarme vs sinais estáveis); regressão = **máquina que descalibra depois de uma manutenção**.

## 3. Cobaias e o ciclo (estrutura dramática)

**Cobaia principal:** CHA₂DS₂-VASc — regra "AVC prévio (S₂) vale 2 pontos" (a aula_21 a chama de "o erro mais comum"). Casos-controle fiéis à aula_21 (gabarito clínico conhecido):
- Caso 1: 68a, masculino, HAS + DM → **score 3 / Anticoagular**
- Caso 2: 55a, masculino, sem fatores → **score 0 / Sem indicação**
- Caso 3: 77a, feminina, IC + HAS + AVC prévio → **score 7 / Anticoagular**
- Caso do clímax: paciente só com AVC prévio, mais nada → **2 pontos** (prova a regra S₂)

**Cobaia secundária (fecha arco da aula_31):** timestamp imutável do checklist — "marcar o mesmo item duas vezes NÃO muda o horário". A máquina faz sozinha os 3 cliques que o professor fez à mão na aula_31.

**Ciclo dramático (GREEN → sabotagem → RED → GREEN):**
1. Pedir os testes (Prompt 1) → `uv run pytest -v` → **VERDE** (o aluno aprende a ler a barra verde como "calibrado").
2. Testar o timestamp (ato intermediário, fecha arco) → verde.
3. **CLÍMAX — sabotagem (Prompt 2a):** pedir ao Claude para introduzir o bug clássico (AVC prévio 2→1) → `uv run pytest -v` → **VERMELHO** (`expected 2, got 1`). Tradução: *"o guardião pegou. Esse paciente seria subtratado — e travou ANTES de chegar perto dele."* Silêncio teatral.
4. Conserto (Prompt 2b) → `uv run pytest -v` → **VERDE**. *"Recalibrado. E quem te avisou não foi um paciente lesado — foi o guardião, de graça, em meio segundo."*

> Justificativa GREEN→RED→GREEN (não o RED→GREEN clássico): o app já existe (S05); o uso real para este público é **regressão** ("pedi melhoria e o Claude quebrou outra regra") — exatamente o que a aula_31 prometeu. "Escrever o teste antes" entra como nota de cultura, não como prática invertida forçada.

## 5. As 2 perguntas conceituais (substituem leitura de código) — Seção 3

**P1 — "Qual regra merece um guardião?"** (priorização). Enunciado: das três — (a) a cor do botão calcular, (b) o AVC prévio valer 2 pontos, (c) o alinhamento do texto — qual, se quebrasse **em silêncio**, é a mais perigosa? **Resposta: (b)** — cosméticos você vê na hora; a regra clínica quebra **invisível e letal** (subtrata). Critério: teste-que-importa = regra cuja quebra é silenciosa E perigosa.

**P2 — "O que um controle precisa ter para servir de teste?"** Enunciado: a máquina lê 96 mg/dL num tubo-controle; isso prova que está calibrada? O que falta? **Resposta: falta saber o valor VERDADEIRO de antemão** (o controle "vale" 100). É a definição de TDD: declara-se o esperado **antes**, depois compara. Conexão: *"é por isso que no prompt eu não digo 'teste a calculadora' — eu digo 'paciente com AVC prévio DEVE dar 2 pontos'; eu entrego o gabarito junto."*

## 7. LGPD + gancho aula_34

**LGPD (Seção 7, orgânico):** os "pacientes" do teste são **fictícios** (controles sintéticos, como a amostra-controle nunca é sangue real) → nenhum dado real entra. E o pytest roda **100% local** (arranca o cabo de rede, funciona igual). Dois reforços: dados de teste sintéticos (boa prática) + execução local (eixo do curso).

**Gancho → aula_34:** *"E como você cria um guardião para uma regra que MUDA? A busca do RAG não dá sempre a mesma resposta exata — ela traz o mais parecido. Como se testa o controle de qualidade de uma coisa que é, de propósito, aproximada? É a próxima aula."* (O gancho S10/CI-CD "o guardião que nem precisa ser acordado" fica para o encerramento da aula_34.)
