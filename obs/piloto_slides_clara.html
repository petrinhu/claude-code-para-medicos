MCP: o cabo que liga o Claude a fontes externas

Analogia clínica

O eletrocardiógrafo já sabe interpretar sinais elétricos. Mas só registra o traçado do paciente através dos eletrodos: os cabos que o conectam à máquina.

Conceito técnico

MCP é o cabo que conecta o Claude Code a fontes externas de dados, como o PubMed. Instala-se uma vez; fica plugado para sempre.
