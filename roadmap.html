Visão Geral do Curso

Este roadmap transforma médicos em desenvolvedores de software clínico. São 12 módulos e 31 aulas, cada uma com aproximadamente 1 hora de duração. Construímos juntos o ClinMd-Tribe: um app completo, offline, rodando no navegador e exportável como .exe para Windows. Usamos Claude Code como "residente de plantão 24h", Git para versionamento, RAG para busca semântica em PDFs médicos e CI/CD com Forgejo e Woodpecker.
